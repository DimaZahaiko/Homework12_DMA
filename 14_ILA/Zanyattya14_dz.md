# Домашнє завдання до Лекції 14 (ILA, VIO)

Два паралельних варіанти. Варіант Б версія Варіанту А, 
що перевіряє ті самі навички (налаштування ILA/VIO, Advanced
Trigger, Capture Control), просто зупиняється на кроці ПЕРЕД
реальним програмуванням плати.

## Варіант А — є робоче залізо (PYNQ-Z1 чи інша плата з JTAG)

1. Візьміть будь-який ваш уже готовий проєкт (MicroBlaze чи
   чистий RTL, без різниці) і додайте ILA на 3-5 сигналів за
   власним вибором.
2. Синтезуйте, реалізуйте, запрограмуйте плату.
3. Задайте тригер на конкретну подію (не просто "сигнал=1" —
   оберіть щось, що реально відбувається у вашій системі рідко
   чи раз).
4. Зробіть скриншот Waveform з ILA після спрацювання тригера.
5. Порівняйте зі скриншотом Waveform Viewer із симуляції ТОГО
   САМОГО проєкту (якщо вона була раніше).

## Варіант Б — немає робочого заліза (і/або тариф Basic)

**Важливо**: у тарифі Basic `mark_debug`/Netlist Insertion і
майстер "Set up Debug" **недоступні взагалі** 
(Basic дає ILA лише через HDL Instantiation, одне ядро, до 5 проб).
Тому цей варіант побудований на Способі Б — ви самі ставите ILA з
IP Catalog і самі вручну з'єднуєте сигнали в коді. Це працює в
Basic без обмежень.

Усі кроки нижче виконуються **в самому Vivado, без фізичної
плати** — Synthesis, Implementation і навіть Generate Bitstream
працюють без підключеного пристрою. Зупиняєтесь лише на самому
останньому кроці (Program Device), якого без плати не зробити.

1. Візьміть будь-який ваш уже готовий Verilog-модуль (свій із
   попередніх лекцій.
2. Згенеруйте ILA.
   IP Catalog → Debug & Verification → Debug → ILA → Customize IP:
   **Number of Probes = 5** (максимум для Basic), для кожної проби
   задайте ширину (за потреби — об'єднайте кілька сигналів в одну
   широку пробу через конкатенацію (об'єднання сигналів) `{}`,
   якщо сигналів більше 5).
4. Generate Output Products.
5. У своєму RTL-файлі (чи окремому top-level) вручну інстанціюйте
   згенероване ядро (`ila_0`), підключивши `clk` і 5 проб до
   реальних сигналів вашого модуля — за шаблоном, який Vivado
   показує після Customize IP (Instantiation Template)
6. Зробіть скриншоти: код інстанціювання ILA у вашому файлі, і
   вкладку Customize IP з вашими налаштуваннями ширини проб.
7. Run Synthesis — переконайтесь, що немає помилок elaboration
   (ILA реально під'єднане, порти збігаються).
8. Run Implementation.
9. Відкрийте Implementation Design → Schematic
10. Зробіть скриншоти:  ILA на схемі
11. Generate Bitstream
